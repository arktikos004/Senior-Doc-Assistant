# 使用手冊

> 給長輩與家人的操作說明：怎麼拍照、結果頁怎麼看、提醒在哪裡、家人怎麼確認與更正、文件櫃與設定；最後一節給開發者。
> 最後更新：2026-11-06

「看有」幫您看懂寄到家裡的帳單、公文、藥袋與發票：拍一張照片，它會告訴您這是什麼、要做什麼、什麼時候前、多少錢，
並把期限列成提醒。它只協助閱讀——**不會替您付款、不會替您回覆，也不提供醫療建議**。

## 1. 打開「看有」

> 從哪裡打開、六個分頁各是什麼，顏色和狀態牌、紅色數字和 ⓘ 的意思。

- 用手機或電腦的瀏覽器打開家人設定好的網址；在架設「看有」的那台電腦上，也可以直接打開 `http://127.0.0.1:8000`。
- 畫面最上面是一條深色的橫列：左邊是「看」「有」兩塊黃色的牌和現在是誰在用，右邊是六個分頁，名稱都是兩個字：**首頁**、**文件**（文件櫃）、**確認**（家人確認）、**複核**（待複核）、**設定**、**手冊**（使用手冊）。目前所在的分頁是黃色的。手機（或字放大到一行排不下時）分頁收在深色橫列右邊的選單圖示（三條線）裡，按一下就打開。
  家人看到「確認」「複核」右上角的紅色小數字，是還在等待處理的件數；用選單圖示時，圖示右上角的紅色數字是兩者加起來的件數。長輩不能確認，所以看不到這些紅色數字。
- 顏色的意思：**黃色的按鈕** 是這一頁最主要的動作，一頁只有一顆；深色框的是其他按鈕；字下面有線的是連結。
  要注意的事寫在小牌上：**紅牌** 是逾期、核對不符或讀不出來，**黃牌** 是快到期或還在等待（例如等家人確認）；只有外框的牌是還沒到的期限。沒事的用淡色的字寫。顏色只是幫忙，牌上一定寫著字。
- 畫面上只留標題與內容，說明都集中在這本手冊。真的重要的事，標題旁有 ⓘ 圖示（**說明**），按一下會在圖示下面跳出一個深色的小框（圖示變成實心）；再按一下圖示、點小框外面或按 Esc 就收起來。
- 手冊首頁可以搜尋，下面依主題分成一篇一篇；首頁也寫著現在的情況：資料在哪裡處理、系統只協助閱讀、核對結果由程式檢查。

## 2. 拍照或選照片（首頁）

> 拍照或選照片、選文件類型、按開始辨識；照片模糊或 PDF 有密碼時怎麼辦。

1. 在「拍照或選一張照片」按 **拍照讀文件**（手機會打開相機），或按 **選照片**（從相簿或電腦選檔）。
   在電腦上，也可以把照片直接拖進虛線框裡放開，和按「選照片」一樣；拖著照片進框時，虛線框會變成深色的實線。一次放一張。
   框裡的灰字寫著可以傳什麼：照片或 PDF，15MB 以內。
   **拍照讀文件** 對每個人都是首頁最醒目的黃色按鈕；家人要確認或複核的事列在下面「要記得的事」的「需要家人協助」（第 4 節）。
2. 選好後這兩顆按鈕會收起來，換成「已選好：」和照片縮圖。看一下有沒有選對；選錯了按 **換一張**。
   系統偵測到照片模糊、或文件的邊角沒拍進去時，縮圖下面會多一行提醒，例如「照片有點模糊，建議換一張再拍。」
   這時建議按 **換一張** 重拍；不重拍也可以直接按「開始辨識」。沒有這行字不代表照片一定清楚，還是請看一下縮圖。
   這個檢查只在家裡這台電腦上做：照片先縮小，傳到這台電腦算一次，不存檔、不留紀錄，也不會交給 AI；PDF 不檢查。
3. 在「這是什麼文件？」選一個：帳單、公文、藥袋、發票／收據、不確定。**不確定可以不選，AI 會自己判斷，而且只在這台電腦辨識。**
4. 按 **開始辨識**。照片上傳時，下面有一條進度條和「已傳幾 %」，請不要關閉畫面；傳好後畫面會換成進度頁：收到照片、AI 照抄文字、程式核對、決定怎麼處理，亮起來的是目前走到的那一步，每一步真的做完才往下走；AI 一次讀一份，前面還有別份時會寫前面還有幾張。讀完會自動打開結果頁。

**選了之後會怎樣**

- 選的類型決定 AI 用哪一種讀法；讀出來是什麼文件，以 AI 讀到的內容為準（發票和收據用同一種讀法，讀完才分得出是哪一種）。
- 稅單、管理費、水電瓦斯費、電信費請選「帳單」；身分證、保單這類不在這五種裡的文件請選「不確定」，
  AI 讀不出是哪一種時，會放進「待複核」交給家人看。
- **藥袋、發票／收據和「不確定」，一律只在家裡這台電腦上辨識**（第 9 節）。
- 上傳時不用分大類：文件依讀到的種類放進「文件櫃」（發票、收據放「財產資產」，帳單放「生活契約」，藥袋放「醫療與保險」）；
  公文要看內容才分得出來，放在「未分類」，家人之後可以指定（第 7.3 節）。

**拍清楚的小訣竅**：在光線充足的地方，把文件放平，整張拍進畫面；放在顏色比紙深的桌面上更好。
請直接按「拍照讀文件」，或選相簿裡的原始照片；經過通訊軟體轉傳的照片常被縮小，小字會變模糊。
系統會先找到照片裡的紙張、把斜拍的紙拉正，光線不均時也會補光，再交給 AI 讀；照片太模糊時這些都幫不上忙，請重拍一張。

**可以上傳的檔案**：照片（JPG、PNG、WEBP、BMP、TIFF）或 PDF，15MB 以內；PDF 只會讀第一頁。

**PDF 有密碼時**（電信費、信用卡這類電子帳單常會加密碼）：上傳後會先出現「這份 PDF 有密碼」。

1. 在「PDF 密碼」輸入密碼。密碼通常寫在寄帳單的通知信或簡訊裡，常見是身分證字號或生日。想確認有沒有打錯，可以按 **顯示密碼**。
2. 按 **解開並辨識**，之後跟一般上傳一樣看結果。上傳時選的類型會照樣帶著。
3. 密碼不對時會寫「密碼不對，還可以再試幾次」；**錯 5 次**、按 **先不要**，或 **30 分鐘**沒處理，這份檔案就會刪掉，要用時重新上傳。

密碼只用來打開這一份，不會存起來，也不會出現在任何紀錄裡。

看到下面這些話時：

| 畫面上的話 | 怎麼辦 |
|---|---|
| 請先拍照，或選一個檔案。 | 還沒選照片，先按「拍照讀文件」或「選照片」 |
| 這個檔案是空的，請重新拍一張。 | 重新拍一張 |
| 只能上傳照片（JPG、PNG、WEBP、BMP、TIFF）或 PDF。 | 換一個檔案 |
| 檔案內容和副檔名對不上，請直接用相機拍一張，或選原始的照片檔。 | 改按「拍照讀文件」直接拍 |
| 檔案超過 15MB。請改拍一張，或選較小的檔案。 | 重拍，或選小一點的檔案 |
| 一次只能放一張，請只拖一張進來。 | 一次拖一張照片進框裡 |
| 這個瀏覽器不能把照片拖進來，請按「選照片」。 | 改按「選照片」 |
| 上傳沒有成功。請檢查網路，再按一次「開始辨識」；還是不行就重新整理這一頁。 | 網路斷了，或這台電腦正在重新啟動。照片還選著，等一下再按「開始辨識」 |
| 找不到這次上傳的進度 | 可能已經處理好，或這台電腦剛重新啟動。到文件櫃找；寫著「還沒讀」的，打開按 **重新辨識**，不用重新上傳 |
| 這份文件處理到一半出了問題 | 看下面那句話：照片已經收好的，按 **回到這份文件**，等一下再按 **重新辨識**；寫「沒有存成文件」的，回首頁再上傳一次 |

## 3. 看結果

> 結果頁先回答這是什麼、多少錢、什麼時候前，再寫核對結果、處理狀態與細節。

結果頁分成三層：最上面的深色看板先回答這份文件的重點，下面是處理狀態與可以按的按鈕，再下面是收起來的細節和原件。

### 3.1 最上面：先回答三個問題

一打開就看得到「這是什麼、多少錢或要做什麼、什麼時候前」，接著一句核對結果，然後是 **聽重點** 和 **查看原件**。
例如帳單會依序寫「這是電費帳單」「1,286 元」「11月20日前繳費」「金額與條碼相符；期限請對照原件。」

| 文件 | 最上面會看到 |
|---|---|
| 帳單 | 應繳金額、繳費期限 |
| 公文 | 發文機關、辦理期限、要做的事（沒有應辦事項時寫主旨） |
| 藥袋 | 「服藥時間表」：早、中、晚、睡前各有哪些藥；「需要時」吃的藥另外列；藥袋上沒印時段的藥列在「未標時段」，時段請依藥袋或詢問藥師；只印次數（例如「每日三次」）的藥也列在這裡，系統不把次數換算成時段。下面寫這張表的狀態，例如「等家人確認 2 天」「家人已確認」 |
| 發票、收據 | 商家、日期、金額 |

- 再上面一行是位置，例如「首頁 / 生活契約 / 電費帳單」；按中間的大類，會打開文件櫃的那一類。
- 沒讀到的項目照實寫，例如「沒有讀到應繳金額」；AI 自己標成讀不清的寫「繳費期限讀不清楚，請看原件」。
- 期限的日期寫成一位一塊的數字牌（例如 11/20），後面的狀態牌寫還有幾天：「還有 12 天」「明天到期」「今天到期」，過了是紅牌「逾期 3 天」。標示已繳費或已辦理後，牌上改寫「已繳費」「已辦理」；取消提醒後就沒有這塊牌。
- 公文的期限是程式依原文算的：「收到本函後15日內」這種寫法，從發文日期算起；家人填了收到日期就從那天算（第 7.2 節）；
  讀不到發文日期時先從上傳那天算，而且一定要家人確認。實際收到信的日子可能比較晚，**期限一律以公文原文為準**。
  寫明日期的（例如「於115年10月31日前」）不受影響；原文算不出日期時（例如「儘速辦理」）照抄公文上的字。

### 3.2 核對那一句

這一句由程式依核對結果組成，不是 AI 寫的，也不受文件上印的字影響。句尾的 ⓘ（**說明**）會寫核對怎麼做的；帳單另外寫「期限由 AI 讀取，請對照帳單。」，
公文另外寫期限是依哪一句、從哪一天算起，家人可以按裡面的 **填收到日期**。

| 看到的字 | 意思 |
|---|---|
| 金額與條碼相符；期限請對照原件。 | 金額和帳單上的超商條碼一樣。**條碼只能證明金額，不能證明帳單屬實**；期限沒有獨立的東西可以比，要自己對照 |
| 日期、金額與 QR Code 相符；商家請對照原件。 | 這些欄位和電子發票左邊的 QR Code 一樣。店名不在 QR Code 裡，要自己對照 |
| 沒有讀到條碼，金額、期限請對照原件。 | 帳單上的條碼沒讀到；電子發票沒讀到 QR Code 時也一樣。程式只檢查格式與合理性，不能證明讀對 |
| 商家、日期、金額請對照原件。 | 收據、公文、藥袋沒有機讀碼可以比，只能檢查格式與合理性（藥袋寫請對照藥袋） |
| 紅字：讀到的金額和帳單上的超商條碼不一樣，請對照原件確認。 | **AI 很可能讀錯**。金額旁邊也會標「和條碼不符」。這種問題一定寫在最上面，不會收起來 |
| 紅字：期限沒通過檢查，請對照原件。 | 格式或合理性有問題，例如期限早於出帳日 |
| 未核對：沒有能自動核對的項目，請對照原件。 | 這份文件沒有做過任何檢查 |
| 紅字：這次的核對沒有完成，請對照原件。 | 核對程式出錯，這份文件會交給人確認 |

### 3.3 處理中、等待複核、讀不出來、系統忙碌

- **處理中**：畫面寫「正在讀這張」。照片已經收好，AI 還在讀，讀好這一頁會自己換成結果。這時還不能更正、改類型或重新辨識。
- **等待複核**：AI 沒把握、核對不符、少了重要的欄位，或不是支援的文件類型（例如保單）。標題下面用一句話說原因，
  例如「AI 對這份文件的讀值沒有把握，請對照原件確認。」家人旁邊有 **更正讀值** 和 **類型不對？**（第 7 節）；長輩看得到原因，要請家人看可以按 **請家人看一下**（第 3.11 節）。
- **這張讀不出來**：會出現「重新拍一張」按鈕，照上面的小訣竅再拍一次。
- **系統暫時忙碌，這張還沒讀**：AI 模型沒有回應，或這台電腦讀到一半重新開機，不是照片的問題。照片還在，不用重拍，也不用重新上傳。
  請等一下再按 **重新辨識**；一直不行的話，請家人看一下這台電腦。

### 3.4 聽重點

- 按 **聽重點**，系統會把最上面的重點唸出來：這是什麼、金額或要做的事、期限、核對那一句；待複核的原因和藥袋的提醒聲明也會唸。帳單、公文、發票、收據不唸 AI 白話解說（內容和重點重複），要看可以往下捲；藥袋會唸，因為藥袋上印的提醒可能只寫在那裡。
  數字一個一個唸（例如 1,286 元唸成「一 二 八 六 元」），比較不會聽錯。
- 唸的時候按鈕會變成「停止朗讀」，再按一次就停。
- 覺得唸太快，可以到「設定」把這台裝置的朗讀速度改成「慢」（第 8.2 節）。
- 如果看到「這個瀏覽器不能朗讀。請改用手機或電腦上的 Chrome、Safari 或 Edge。」，換一個瀏覽器就好。
- **查看原件** 會跳到您上傳的照片（第 3.9 節）。

### 3.5 處理狀態：已存檔和已繳費是兩件事

往下看「處理狀態」。文件和事情分開寫，**「已存檔」只代表文件收進文件櫃，不代表已繳費或已辦理。**

| 這一列 | 會看到 | 可以按 |
|---|---|---|
| 文件 | **已存檔**（AI 讀到的內容通過核對，該有的欄位也都有，文件收在文件櫃）或 **等待複核**，和上傳時間 | 家人：**更正讀值**、**類型不對？** |
| 繳費（公文寫「辦理」，發票的領獎提醒寫「領獎」） | **還沒標示已繳費** | **已繳費**（公文是 **已辦理**） |
| | **已繳費**，和誰、哪天標示的 | **改回未繳**（公文是 **改回未辦**），隔多久都可以 |
| 提醒 | **已列入提醒**：不用等任何人確認，已經生效；完成或取消前會一直列在首頁「要記得的事」 | **查看待辦**、**取消提醒** |
| | **已取消提醒**：首頁「要記得的事」不再列出 | **恢復提醒** |
| 提醒、服藥時間表 | **等家人確認 3 天**（當天寫「等待家人確認」）、**家人已確認**、**已退回** | 長輩：**查看待辦**；家人：**去確認**（第 6 節） |

- 按 **已繳費**、**已辦理** 只是記錄，讓家人知道；系統不會付款，也不會查核。這件事會移到首頁「已完成」，寫出誰、哪天標示的。
- 按 **取消提醒** 不會再問一次，畫面上方出現「已取消提醒」。按錯了沒關係，同一個位置會變成 **恢復提醒**。
- 還在等家人確認的事不能標示已繳費，也不能在這裡取消；已退回的也一樣。**系統不會通知家人**，提醒只列在首頁「要記得的事」，不會傳訊息或響鈴。想請家人快點看，可以按 **請家人看一下**（第 3.11 節）或打電話。
- 家人更正過這份文件後，舊的提醒會換成新的。從更正前就開著的舊畫面按按鈕時，會看到「這個提醒已經換成新的了」，
  請回結果頁看最新的提醒。
- 發票在這一區下面有 **統一發票對獎**（第 5.1 節）。

### 3.6 長輩和家人看到的按鈕

同一個網站，依登入身分（第 8.5 節）顯示不同的主要操作。結果頁只有一顆黃色的主要按鈕：**聽重點**；讀不出來的頁面是 **重新拍一張**，系統忙碌的頁面是 **重新辨識**。

| 身分 | 可以做的事 |
|---|---|
| 長輩 | 聽重點、查看原件、請家人看一下、查看待辦、標示已繳費或已辦理、取消或恢復提醒、拍下一張；任何待確認或家人確認過的事項都能退回 |
| 家人 | 長輩能做的全部，再加上更正讀值、類型不對？、去確認、刪除這份文件。待複核的文件，黃色的主要按鈕是 **更正讀值** |
| 只能查看的人 | 看內容、聽重點、查看原件，不能標示或更改 |

等家人確認的事，長輩只會看到等待的狀態，不會被帶到按不了的頁面。

### 3.7 AI 白話解說

- 「AI 白話解說」是 AI 讀完整理的一小段話（80 字以內），旁邊標著「AI 產生」。**重要的日期與金額請對照原件。**
- AI 沒有給解說時，標題會變成「重點整理」，內容是系統用讀到的欄位拼成的句子。
- 家人更正過讀值後，AI 的舊解說不再顯示，改成「重點整理」，標題旁的 ⓘ（**說明**）裡寫「家人更正過讀值，這段是系統依更正後的欄位整理的。」
- 藥袋頁「服藥時間表」旁的 ⓘ（**說明**）一定有這句話：「本系統只協助閱讀，不提供醫療建議；用藥請依醫師與藥師指示。」按 **聽重點** 也會唸出來。

### 3.8 收起來的細節：核對細項、讀到的內容

按一下就展開，要緊的問題已經寫在最上面。

**核對細項** 列出程式做過的每一項檢查。這些檢查由程式完成，不是 AI 自己打分數。

| 畫面上的字 | 意思 |
|---|---|
| 相符 | **只用在電子發票與帳單**：程式把 AI 讀到的值，和發票左邊 QR Code 或帳單上超商條碼裡的資料比對，結果一樣。這些機讀碼是開立時印上去的資料，和 AI 怎麼看照片無關，所以「相符」是比較有力的證據 |
| 不符 | 和 QR Code 或超商條碼不一樣，AI 很可能讀錯了。這份文件不會自動存檔，會交給人確認 |
| 通過 | 程式只檢查格式與合理性（例如統一編號的檢查碼、日期在不在合理範圍）。「通過」只代表沒有明顯讀錯，**不能證明讀對** |
| 沒通過 | 格式或合理性有問題，請對照原件 |
| 無法核對 | 這一項沒有東西可以比對，例如找不到 QR Code 或超商條碼 |

- 「驗證信心」依核對結果計算，不是 AI 自評。只有格式與合理性檢查的文件，驗證信心最高只到 85%。

**讀到的內容** 是 AI 讀到的每一個欄位；藥袋另外列出「藥品（照藥袋上的字抄錄）」。最上面的「辨識來源」寫的是哪一個模型讀的。

- 欄位旁可能標著「與 QR 相符」「與條碼相符」「已檢查」或「不符」；讀不清的欄位寫「讀不清楚，請看原件」，該有卻沒讀到的寫「沒有讀到」。
- 讀錯了，家人可以按裡面或「處理狀態」的 **更正讀值**（第 7 節）。家人更正過的欄位，下面會寫「家人改過，原本讀成 …」，看得出哪些是 AI 讀的、哪些是家人改的。

### 3.9 其他區塊

- **提醒與待辦**（按一下展開）：這份文件產生的期限提醒或服藥時間表，以及它們現在的狀態。要家人確認或家人確認過的事項，下面有 **退回這個事項**，按了會先問一次。
- **原件**：您上傳的照片（電腦版在右邊，手機和平板在下面）。按「放大看原件（另開新頁）」可以看清楚細節；
  PDF 沒辦法在頁面上預覽，請按「另開原檔」。
  原件下面的 **系統處理後送給 AI 的影像**（按一下展開）是系統找到紙張、拉正、調整光線後交給 AI 讀的那一張，
  看得出有沒有裁錯；這張是依目前的設定重新產生的，不會另外存檔。
- **拍下一張**：按了回首頁拍下一份。

### 3.10 這張可能已經上傳過

同一張文件傳了兩次時，最上面的重點下面會出現「這張可能已經上傳過」，寫出另一份是哪天上傳的，按「看之前那一份」
（或「看之後那一份」）就能打開它。下面兩種情況才會出現：

- 上傳的檔案一模一樣（同一張照片或同一個 PDF 又傳了一次）。
- 兩份都是發票，發票號碼都和發票上的 QR Code 一樣，而且號碼相同。只有 AI 讀到、沒經過 QR Code 核對的號碼不算。

系統不會自動刪除。確定是同一張的話，家人可以在其中一份的頁面把它刪掉。

### 3.11 請家人看一下

看不懂或不放心時，按 **請家人看一下**。手機會打開分享選單，選 LINE 或簡訊傳給家人就好；
傳出去的只有這一頁的網址和「請幫我看這份文件」，不含文件內容，家人要登入「看有」才看得到。
瀏覽器不能分享時會改成複製連結，畫面寫「已複製連結，請貼給家人。」**系統不會自己通知家人**，一定要傳出去。

### 3.12 最下面：退回與刪除

- **這份讀不清楚，退回重拍**（等待複核的文件才有）：文件改成「讀不出來」，請長輩重新拍一張。按了會先問一次。
- **刪除這份文件**（只有家人）：照片、讀到的內容、提醒和這份文件的操作紀錄都會刪掉，不能復原。按了會先問一次。
- **操作紀錄**（按一下展開）：這份文件誰、什麼時候做了什麼。

## 4. 首頁「要記得的事」

> 期限與服藥提醒怎麼分組、怎麼標示已繳費，以及取消或恢復提醒。

首頁最上面一定是 **拍照讀文件**。下面的「要記得的事」分組列出，旁邊寫總共幾筆；首頁放 6 筆，更多的按 **查看全部 N 筆**。

「要記得的事」是一整塊深色的看板，一筆一列，每一列都對齊：最左邊是期限（數字一位一塊牌，例如「11/20 前」；不是今年的另外寫年份），
接著是這是什麼、多少錢（例如「電費 1,286 元」），下一行是開單單位；再來是狀態牌，最右邊是按鈕。
沒有期限的（被退回的文件、服藥時間表），期限那一格是空白的暗牌。
按 **看文件** 打開那份文件，按 **已繳費**（公文是 **已辦理**）標示做完了。每一種按鈕在每一列都在同一個位置，這一列用不到的那一格就空著。

1. **已逾期**：過了期限還沒完成的（紅牌寫「逾期 N 天」，最近才過期的在前）
2. **被退回的**：別人退回的文件與事項。文件寫「請重新拍：電費帳單」，事項寫「已退回」，下面寫是誰、哪天退回的。自己退回的不會列給自己
3. **快到期**：7 天內到期的（近的在前；三天內是黃牌，寫「今天到期」「明天到期」「還有 2 天」，更遠的是只有外框的牌）
4. **需要家人協助**：等待家人確認的事（黃牌；等了一天以上會寫「等家人確認 3 天」），以及核對不符或檢查沒通過的文件（紅牌）。
   家人看到的是 **去確認**，直接打開那一件；還有文件在待複核時，多一列「2 份文件等您複核」和 **去複核**。長輩看到的是 **看文件**，打開看得到還在等家人
5. **其他**：更遠的期限，以及家人已確認的服藥時間表

- 期限過了還沒完成的提醒會一直留著，直到標示「已繳費」「已辦理」或取消提醒。
- 舊帳單這類不用再提醒的，按清單上的 **取消提醒**：會打開那份文件，按錯了在同一個位置按「恢復提醒」。還在等家人確認的，到「家人確認」退回。
- 退回的通知按 **已讀** 就收起來；退回超過 30 天的也不再列。已取消的提醒不會列在上面。
- **查看全部** 那一頁下面收著「已完成」（全部，按錯了可以改回）和「已取消的提醒」（寫是誰、哪天取消的）。
  要恢復，打開那份文件按「恢復提醒」。
- 標示「已繳費」「已辦理」的提醒改列在下面的「已完成」，保留 7 天；「已完成」平常收著，按一下才打開。
  之後要改回，打開那份文件按「改回未繳」「改回未辦」。
- **提醒只有打開「看有」時才看得到**：系統不會傳訊息、不會響鈴，也不會加進手機的行事曆。
  請每天打開看一下，或請家人幫忙看。
- 下面的「最近看過的文件」列出最近 8 份，一列一份：標題（按了打開那份文件）、上傳時間、狀態，三欄上下對齊。
  狀態一樣是「已存檔」「等待複核」「讀不出來」：要注意的寫在小牌上（黃牌是等待複核或還在讀，紅牌是讀不出來），已存檔是淡色的字。「已完成」收在最下面。

## 5. 文件櫃

> 所有文件依四大類整理，可以搜尋文件，也可以替發票對獎。

「文件櫃」把所有文件依四大類整理：身分證明、財產資產、醫療與保險、生活契約。

- 最上面可以 **找文件**：打幾個字按放大鏡（找），每個字都要出現、順序不拘，例如「電費 11月」「區公所」「1286」。
  找的是讀到的內容（標題、機關或商家、主旨、金額、號碼、白話解說），只在這台電腦的資料裡找。選了一類時只找那一類。

- 最上面是四大類和各有幾份，一類一格，按一格就只看那一類，選中的那一格是黃色的。每一類放什麼：身分證明（身分證、健保卡、戶口名簿）、財產資產（發票、收據、稅單）、
  醫療與保險（藥袋、保單、醫療收據）、生活契約（水電瓦斯、電信、租約）。
- 下面依大類列出文件，和首頁「最近看過的文件」一樣是標題、上傳時間、狀態三欄；每一列按下去就是那份文件的結果頁。「讀不出來」和「等待複核」的文件也算在份數裡。
- 公文要看內容才分得出來，放在「未分類」，列在最後；家人可以在「更正讀值」指定它屬於哪一類（第 7.3 節）。

### 5.1 統一發票對獎

從文件櫃「財產資產」旁邊的 **統一發票對獎** 進去；發票的結果頁也有同一顆按鈕，會直接打開那張發票的那一期。

1. 上面列出有發票的每一期（例如「115 年 9、10 月期」），目前這一期是黃色的；按一下換成那一期。
2. 家人照財政部公告輸入特別獎、特獎和三組頭獎號碼，再照公告選 **領獎期限**（遇到假日會順延，所以要照公告上的日期填），按 **對獎**。
   每個號碼都是 8 位數字，用全形數字、中間有空白或連字號都可以；填錯時，離開那一格就會在下面寫「請輸入公告上的 8 位數字」。
   長輩看得到號碼，但不能改。
3. 下面的「比對結果」列出這一期讀過的發票：可能中獎的寫「可能中了六獎（200 元）：末 3 碼和頭獎第 3 組一樣」，
   沒中的寫「沒有中獎」。
4. 可能中獎的按 **加進「要記得的事」**，首頁就會列出「兌領統一發票獎金」，日期是領獎期限。不需要的話，
   到那張發票的結果頁按「取消提醒」。

- 只比對發票號碼經過 QR Code 核對、而且相符的發票。AI 讀錯一個字就可能對錯獎，所以沒經過核對的只寫張數，
  請拿正本自己對照公告。
- 有打統編的發票（QR Code 上記載了買方統一編號）依規定不能兌獎，不比對，只寫「另有 N 張有買方統編（打統編）」；
  這種發票的結果頁也沒有「統一發票對獎」按鈕。
- 結果只供參考，以公告和發票正本為準。系統不會替您領獎，也不會去查財政部的資料；中獎發票請保留正本。

## 6. 家人確認（給家人）

> 需要家人點頭的事一次看一件：沒問題按確認，不對按退回。

「家人確認」只放需要家人點頭的事，**一次看一件**，標題下面寫「第 1 件，共 3 件」，整頁只有一顆黃色的 **確認**。
家人打開首頁時，要確認的事列在「要記得的事」的「需要家人協助」，按 **去確認** 直接打開那一件；
還有文件在待複核時，多一列「N 份文件等您複核」和 **去複核**（第 4 節）。

- **藥袋的服藥時間表**：一律要家人確認才算數。
- **轉到待複核的帳單或公文，它們的期限提醒**：已存檔的帳單與公文會自動列入提醒，不會出現在這裡。

畫面上寫著這是什麼、來自哪一份文件、什麼時候上傳，並有「看原件與全文」連結；原件照片在寬螢幕放在旁邊、手機放在內容下面，方便逐項對照。等了一天以上會寫「已等 N 天」。
期限類的事排成一塊深色的看板：數字牌寫期限，旁邊寫這是什麼和完整的日期，過了期限有紅牌。
服藥時間表旁的 ⓘ（**說明**）有藥袋聲明；公文的期限旁的 ⓘ（**說明**）寫期限是從哪一天算起。

- 沒問題就按 **確認**，狀態變成「家人已確認」，這件事會列進首頁「要記得的事」，畫面接著換下一件。
- 不對就按 **退回**。畫面中間會跳出確認框，例如「確定要退回「服藥時間表」嗎？」「退回後就不會生效。」：
  - 按 **確定退回**，狀態才變成「已退回」，畫面接著換下一件。**退回之後在系統裡沒辦法復原。**
  - 按 **先不要**（或按鍵盤的 Esc）就什麼都不做。框一打開，預設選在「先不要」上，不小心按到 Enter 也不會退回。
  - 確認框剛跳出來的半秒內，點框上的按鈕不算數——不小心連點兩下「退回」，也不會沒看清楚就退回。
- 想先看別件，按 **看下一件**；最後一件的連結是 **回到第 1 件**。
- 全部處理完會寫「都確認完了」，按 **回首頁**。
- 在結果頁「處理狀態」按 **去確認**，會直接打開那一件。那一件如果已經不用確認，上面會寫「這件事可能已經有人處理了。」，下面接著顯示還沒處理的第一件。
- 按確認或退回時看到「這件事可能已經有人處理了，請回「家人確認」看最新狀態。」，代表別人已經按過了。
- 服藥時間表或期限讀錯了，不必退回：到那份文件按「更正讀值」改正（第 7 節），系統會重新整理服藥時間表或重算提醒。
- 從家裡以外的地方登入時，權限看「家庭成員」的名單（第 8.5 節）：家人可以確認與退回；長輩可以退回，畫面上寫「等待家人確認」，沒有 **確認** 按鈕；名單外的登入者只能查看。
  在架設「看有」的那台電腦上直接打開時，權限等同家人。

## 7. 待複核與更正讀值（給家人）

> AI 沒把握或核對不符的文件放在待複核，家人對照原件更正讀值。

### 7.1 待複核清單

AI 沒把握、核對不符、少了重要的欄位，或不是支援的文件類型（例如身分證、保單），會放進「待複核」。
清單上每一份都寫出白話的原因、上傳時間與驗證信心（沒有可核對項目的寫「沒有可核對的項目」）。按一份就打開它的「更正讀值」。

### 7.2 更正讀值

任何類型的文件都能更正：待複核的文件從清單進來；已存檔的文件，在結果頁「處理狀態」按 **更正讀值**。
讀不出來的文件沒有讀值可改，請重新拍一張。

電腦上左邊是原件、右邊是表單，原件跟著畫面固定在左邊；手機和平板的原件在表單上面。**對照原件，只改讀錯的地方。**

**放大原件**：按 **放大** 照片就放大，框裡可以上下左右捲動；按 **縮回** 回到整張。也可以直接按照片，會放大按的那個地方，再按一下縮回。
按 **另開新頁看原件** 是開新分頁，這一頁已經填的字還在。

**有問題的欄位排在最前面，一次看一個**，其他的排在後面的「其他欄位」。每一個有問題的欄位先寫一行「欄位名稱：為什麼要看」，例如「金額：和發票上的 QR Code 不符」。
打開頁面時只展開第一個，游標就在那一欄；填錯重畫時，游標在第一個要改的欄位，它是有問題的欄位就展開它。
其他有問題的欄位收成一行，按那一行就展開，原本展開的收起來。
收起來只是看不到，已經填的字都還在，按儲存時一起送出；改過還沒儲存的，那一行旁邊寫「已修改，尚未儲存」，寫錯的寫「要修改」。
沒有開 JavaScript 的瀏覽器會全部展開。

為什麼要看：

| 畫面上寫的 | 意思 |
|---|---|
| 和發票上的 QR Code 不符、和帳單上的超商條碼不符 | 讀到的值和機讀碼上的不一樣。下面會寫機讀碼上的值；按 **改成…** 只是把值填進欄位，還要按儲存才算數 |
| AI 讀不清楚 | AI 標示這一欄讀不清楚，請看原件 |
| AI 沒有讀到 | 必填的欄位是空的，請對照原件填上 |
| 檢查沒通過：… | 程式的規則檢查沒通過（例如繳費期限早於開單日期），後面是程式的說明 |

這些原因只看核對結果與 AI 標示讀不清的欄位，不看 AI 對自己的信心。沒有標出問題不代表讀對，一樣請對照原件；
一欄都沒有時，畫面寫「這張表單上的欄位沒有標出問題，請對照原件確認。」

每個有問題的欄位下面有 **下一個問題：…**，按了收起這一個、展開下一個，游標跟著過去；最後一個寫 **下一步：儲存更正並重新核對**，
按了全部收成一行（改了什麼一眼看得到），游標停在儲存按鈕。

手機和平板上，每個有問題的欄位下面還有 **看原件**（藥品是每一種藥下面各一個）：同一張原件就在那一欄下面展開，按 **收起原件** 收回。不會換頁，已經填的字都還在。
PDF 沒辦法在頁面裡顯示，這裡寫 **另開原檔對照**，開新分頁看。

| 文件 | 表單上可以改的 |
|---|---|
| 帳單 | 帳單種類（電費、水費、瓦斯、電信、其他）、繳費期限、應繳金額（元）、開單單位、開單日期 |
| 公文 | 發文機關、發文日期、收到日期（「收到後幾日內」的期限從這天算；沒填就從發文日期算）、主旨、期限原文（照公文上的寫法，例如「收到本函後15日內」；日期由系統計算）、發文字號、應辦事項（一行一項） |
| 藥袋 | 醫療院所、調劑日期；每一種藥的藥名、用法（照藥袋上的字）、什麼時候吃（早、中、晚、睡前、需要時，可以選好幾個）、天數。少一種藥就按「再加一種藥」 |
| 發票、收據 | 日期、商家、金額、幣別（台幣填 NTD）、發票號碼 |

- 標紅色星號（*）的欄位一定要填，其他可以空白。
- 框下面的灰字是填寫要求，例如發票號碼「2 個英文字母加 8 位數字」、金額「只寫數字」、應辦事項「一行寫一項」；沒有格式要求的欄位不寫。
  寫錯時，離開那一欄就會在框的正下方寫怎麼改，不用等到儲存；儲存時伺服器會再檢查一次。
- 日期用日曆選；沒有日曆的瀏覽器可以寫 2026-10-20 或民國年（例如 115/10/20），系統會換算。
- 帳單種類、這份文件屬於哪一類是下拉選單；藥袋「什麼時候吃」可以勾好幾個。
- 藥袋只照抄藥袋上印的字；系統不判斷劑量或用法，存檔後服藥時間表仍要家人確認。
- 文件的種類（例如帳單、收據）不能在這張表單改，要改請按上面的 **類型不對？**（第 7.7 節）。
- 改好之後按 **儲存更正並重新核對**；不想存就按 **不儲存，回到結果頁**。按下儲存之後按鈕會變成「儲存中…」、
  下方寫「正在儲存更正並重新核對，請不要關閉這個畫面。」，等它跳回結果頁就好，不用再按一次。

### 7.3 這份文件屬於哪一類

表單下面的「這份文件屬於哪一類」是下拉選單：身分證明、財產資產、醫療與保險、生活契約、未分類。它只決定文件放在文件櫃的哪一類。

- 什麼都沒改就按儲存，畫面上方寫「沒有改動」。只改類別、讀值沒有變動時，畫面上方出現「已更新類別」；不會重新核對，已取消的提醒、已確認的服藥時間表都維持原狀。

### 7.4 儲存之後

- 畫面回到結果頁，上方出現「已更正」，下一行寫改了什麼，例如「繳費期限、應繳金額已更新，舊提醒已取代」。
  只列真的改動的欄位，寫法不同但值一樣的不算（例如 1286 寫成 1,286）；同時改了類別會多寫「類別」。
- 程式會**重新核對一次**，並**重新計算提醒**（帳單、公文）或**重新整理服藥時間表**（藥袋）。
  原本有提醒、也算出新的，才寫「舊提醒已取代」（藥袋寫「舊的服藥時間表已取代」）；
  原本有提醒、卻算不出新的（例如繳費期限改成早於開單日期，或發票上從對獎頁加的領獎提醒），寫「舊提醒不再生效」；原本沒有提醒就不寫。
  公文讀不到發文日期時，期限仍從原本上傳的那天起算，不是更正的那天。
- 核對都沒問題、該有的欄位也都有，文件就變成「已存檔」；還有問題（例如金額和 QR Code 還是不一樣），
  文件會留在（或改放到）「待複核」並說明原因。
- 改的是同一份文件，不會多出一份。結果頁「讀到的內容」會寫哪些欄位是家人改的、原本讀成什麼。
- 還有別份待複核時，上方會出現「還有 N 份待複核，看下一份」，按了直接打開下一份的更正頁。

### 7.5 填錯時

存不進去時，畫面會寫「有 N 個地方要修改，請看下面紅字的說明。」，已經填的內容都還在。紅字就在那一欄的框正下方，照著改好再按一次：

| 紅字 | 怎麼改 |
|---|---|
| 這一欄必填，請對照原件填上。 | 這一欄不能空白 |
| 請填正確的日期，例如 2026-10-20。 | 日期寫法不對 |
| 請輸入數字，例如 1286。/ 金額要大於 0。 | 金額只寫數字，不要加「元」 |
| 請輸入天數的數字，例如 7。 | 天數只寫數字 |
| 請填 3 個英文字母，台幣填 NTD。 | 幣別寫法不對 |
| 請輸入 2 個英文字母加 8 位數字，例如 AB12345678；不是台灣的統一發票就空著。 | 發票號碼寫法不對（中間有連字號或空白沒關係；收據的號碼不限格式）；國外的發票沒有這種號碼，空著就好 |
| 日期沒有填完整，請把年、月、日都填好。 | 日期只填了一部分；填好年、月、日再存。不想填就整欄清掉 |
| 太長了，最多 500 個字。 | 縮短一點 |
| 收到日期不能晚於今天。/ 收到日期不能早於發文日期。 | 對照信封或收到的那天重填 |

### 7.6 退回（品質不足）

照片太糊、沒辦法判斷時，在待複核文件的更正頁最下面按 **退回（品質不足），請長輩重新拍一張**。會跳出確認框
「確定要退回這份文件嗎？」「這份文件會改成「讀不出來」，請長輩重新拍一張。」：按 **確定退回** 才會退回，按 **先不要** 就不退。
退回後，這份文件變成「讀不出來」，它的提醒也不再生效；請重新拍一張。

### 7.7 改文件類型（類型不對？）

AI 把文件的種類判錯時（例如收據讀成帳單），家人可以在結果頁標題旁，或更正頁上方按 **類型不對？**。

1. 在下拉選單選這份文件其實是哪一種：發票、收據、藥袋、帳單、公文或其他（現在的類型不會列出來）。沒選就按，框的正下方會寫「請選一個類型。」
2. 按 **重讀這份文件**。系統會照這個類型在**這台電腦**重讀一次（不會送到雲端），再重新核對。
3. 舊的讀值與提醒會換成新的，舊提醒不再生效，也不能恢復；操作紀錄會寫是誰從什麼類型改成什麼類型。
   改成藥袋時，服藥時間表要家人確認才生效。

模型沒有回應時，畫面會寫「這次沒有讀成，類型沒有改」：原本的讀值和提醒都還在，等一下再試就好。原件已經不在的文件不能重讀，請重新拍一張。

## 8. 設定

> 系統狀態、這台裝置的字級、全家的系統設定、資料管理與家庭成員。

「設定」有系統狀態、這台裝置、系統設定、資料管理四塊；家人另外看得到「家庭成員」。

### 8.1 系統狀態（只看，不能改）

寫出現在的辨識模式與本機的 AI 模型連不連得上、使用的模型、哪些文件只在這台電腦處理、自動存檔門檻，以及版本。
看到「模型連不上」時，請家人或管理者檢查家裡那台電腦。

### 8.2 這台裝置

- **字級**：標準、大、特大。**朗讀速度**：慢、標準。
- 改了馬上生效，只存在這台手機或電腦，不影響家裡其他人的手機。
- 看到「這個瀏覽器不讓網頁記住設定（例如無痕模式），換頁後會回到預設。」時，換成一般的瀏覽器視窗再設一次。

### 8.3 系統設定（會影響全家）

- **辨識模式**：「只用這台電腦」或「可以用雲端備援」。家裡那台電腦還沒設定雲端的帳號與金鑰時，雲端備援不能選。
  從「只用這台電腦」改成雲端時，按「儲存設定」會先跳出確認框「確定要開啟雲端備援嗎？」，按 **確定開啟** 才會改。
- 不論選哪一種，**藥袋、發票／收據，以及選「不確定」的文件一律只在這台電腦處理，這一項不能關**。
- **自動存檔門檻**：驗證信心達到這個比例才自動存檔，其餘交給家人複核。按一下選 80%、85%、90%、95%，只能調得更嚴，不能低於 80%。
- 按 **儲存設定**；畫面上方出現「已儲存設定」（沒改任何東西時是「設定沒有變動」）。
- 下面的「最近的設定變更」列出什麼時候、改成什麼；從外面經登入使用時，也會寫是哪個帳號改的。

### 8.4 資料管理

- **匯出全部紀錄**：下載一個檔案，裡面有所有文件的讀值、提醒與服藥時間表、更正紀錄與設定變更；不含照片。
  **檔案裡有文件內容，請存在安全的地方。**
- **刪除全部資料**：會先跳出確認框「確定要刪除全部資料嗎？」「所有文件的照片、讀值、提醒與更正紀錄都會刪除，無法復原；
  設定與設定變更紀錄會保留。」按 **確定刪除** 才會刪。刪完回到首頁，上方出現「已刪除全部資料」。
  **刪除後無法復原**，需要的話請先匯出。
  - 只想刪一份時，家人可以在那份文件的結果頁刪除；同樣無法復原。
  - 沒刪乾淨時，畫面會照實說：有照片檔刪不掉，回首頁的訊息會提醒請管理者檢查資料夾；處理紀錄檔刪不掉
    （例如正被別的程式開著），會出現「有些資料還沒刪掉」，寫明哪些已刪、哪些沒刪，關掉那個程式後回設定頁再按一次；
    資料庫正在忙時會出現「資料沒有刪除」，什麼都還沒刪，稍後再試。

### 8.5 家庭成員

從外面登入時，用登入的電子郵件對照這份名單，決定能做什麼：

- **家人**：確認服藥表、更正讀值、管理成員與資料。
- **長輩**：上傳、查看、退回事項，取消或恢復提醒。
- **名單外的登入者**：只能查看。

在「設定」按 **管理家庭成員**：

- 加入成員：填登入時使用的電子郵件，選「家人」或「長輩」，按 **加入成員**。稱呼可以不填；電子郵件要填完整，例如 name@example.com。
- 已經在名單上的成員，可以改稱呼與角色，按 **儲存變更**；不需要了按 **移除成員**，按了會先問一次，移除後這個人只能查看。
- 至少要保留一位家人。要把最後一位家人改成長輩或移除時，會在那位成員下面寫「至少保留一位家人；請先加入另一位家人。」

家人在每份文件的結果頁最下面可以展開「操作紀錄」，列出最近 50 筆確認、退回、更正與提醒操作，寫明時間、誰做的、當時的角色。

> **瀏覽器沒有開 JavaScript 時**：切到雲端備援、刪除全部資料、家人確認與更正頁的「退回」，按下去會先多出一頁確認頁
> （同樣的問題、「先不要」與「確定…」兩個按鈕），按「確定…」才會生效。

## 9. 隱私

> 文件在哪裡辨識、哪些一律只在這台電腦上，以及照片和結果存在哪裡。

- 預設**所有文件都在家裡這台電腦上辨識**，不會送到雲端。
- 家人可以在「設定」改成「可以用雲端備援」：上傳時選「帳單」或「公文」的文件會交給雲端模型讀取；
  **藥袋、發票／收據，以及選「不確定」的文件，仍然只在這台電腦上辨識**，這一項不能關。
  使用手冊的首頁會寫出目前是哪一種模式。
- 在哪裡辨識只看上傳時選的類型。雲端模式下請選對：醫院、診所的帳單或收費單請選「發票／收據」或「不確定」，
  選了「帳單」就會送到雲端；把藥袋選成帳單或公文也一樣。照片在辨識前就已經送出，事後收不回來；不確定時請選「不確定」。
- 送給 AI 之前，系統會先去掉照片裡的拍攝地點（GPS）等資訊。
- 照片和結果存在這台電腦裡；瀏覽器不會把原件留在快取裡。
- 要拿走或清掉所有資料，用「設定」的「匯出全部紀錄」與「刪除全部資料」（第 8.4 節）。
- 從家裡以外的地方用手機打開時，登入由 Cloudflare Access 負責，設定方式見[部署指南](部署指南.md)；畫面和照片會經過 Cloudflare 加密轉送。第一次登入會先看到「資料怎麼用」，寫明存了什麼、放在哪裡、誰看得到、怎麼刪，按「我看過了，開始使用」才繼續。

## 10. 系統不做的事

> 不付款、不給醫療建議、不保證讀對，也不推播通知。

- **不付款、不送出回覆、不簽署任何東西**。要不要繳、要不要回覆公文，由您和家人決定。
- **不給醫療建議**：不解釋藥效、用途或副作用，也不把「一天三次」換算成早中晚；用藥請依醫師與藥師指示。
- **不保證讀對**：AI 可能讀錯。電子發票能用 QR Code 比對，帳單能用超商條碼比對金額；其他文件與其他欄位，請一定對照原件。
- **不推播通知**，也不加進手機行事曆；提醒只列在首頁「要記得的事」。
- 只自動判讀發票、收據、帳單、公文、藥袋（稅單、管理費這類當帳單讀）；身分證、保單等其他文件交給家人確認。PDF 只讀第一頁。

  展示模式的讀值是預錄的模擬資料（安心說明會寫「展示模式」）；核對、決策與行動都是真實程式的結果。
- 設定：`config.yaml`（每一項都有註解）；設定頁能改的辨識模式與門檻存在 SQLite，蓋過 `config.yaml`（見[系統架構](系統架構.md)第 11 節）。
- 系統怎麼運作：[系統架構](系統架構.md)；對外部署：[部署指南](部署指南.md)。

### 建立標準答案

`tools/evaluate.py` 找不到標準答案時會請您看這一節。

- 在專案根目錄執行 `python tools/make_sample.py --einvoice`，會在 `data/samples/einvoice/`
  產生範例電子發票與它自己的標準答案 `labels.csv`；`tools/evaluate.py` 預設就讀這個資料夾（`--samples` 可改）。
- 欄位：`檔名,doc_type,date,vendor,amount,invoice_number`（多的欄位不讀）；日期一律西元 `YYYY-MM-DD`；
  `doc_type` 必填，其他欄位留空就不列入比對。
- 不要把真實文件或真實的標準答案放進 `data/samples/`；`--samples` 指到 `data/samples/` 根目錄時工具會警告。
- 評測在 GPU 電腦執行：`tools/evaluate.py --model gemma4:12b`（沒有模型時可先用 `--mock` 確認流程跑得通，Mock 的結果不是模型表現）。
