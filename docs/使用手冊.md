# 使用手冊

> 給長輩與家人的操作說明:怎麼拍照、結果頁怎麼看、提醒在哪裡、家人怎麼確認與更正、文件櫃與設定;最後一節給開發者。
> 最後更新:2026-10-03

「看有」幫您看懂寄到家裡的帳單、公文、藥袋與發票:拍一張照片,它會告訴您這是什麼、要做什麼、什麼時候前、多少錢,
並把期限列成提醒。它只協助閱讀——**不會替您付款、不會替您回覆,也不提供醫療建議**。

## 1. 打開「看有」

- 用手機或電腦的瀏覽器打開家人設定好的網址;在架設「看有」的那台電腦上,也可以直接打開 `http://127.0.0.1:8000`。
- 畫面有五個地方:**首頁**、**文件櫃**、**家人確認**、**待複核**、**設定**。電腦版在左邊;手機和平板按畫面上方的「選單」。
  「家人確認」「待複核」旁邊的數字是還在等待處理的件數;手機和平板的「選單」按鈕上是兩者加起來的件數。
- 每一頁都有三句安心說明(電腦版在左下,手機和平板在最下面):資料在哪裡處理、系統只協助閱讀、核對結果由程式檢查。

## 2. 拍照或選照片(首頁)

1. 在「拍照或選一張照片」按 **拍照**(手機會打開相機),或按 **選照片**(從相簿或電腦選檔)。
2. 選好後會出現「已選好:」和照片縮圖,看一下有沒有選對。
3. 在「這是哪一類?」選一個:不確定、身分證明、財產資產、醫療與保險、生活契約。**不確定可以不選,AI 會自己判斷。**
4. 下一列會跟著換成這一類常見的文件,選一個(不確定也可以不選):

   | 這是哪一類? | 下一列可以選 |
   |---|---|
   | 不確定(沒選) | 藥袋、帳單、發票、收據、公文、不確定 |
   | 身分證明 | 身分證、健保卡、戶口名簿、駕照、護照、印鑑證明、不確定 |
   | 財產資產 | 發票、收據、稅單、存摺、房地權狀、公文、不確定 |
   | 醫療與保險 | 藥袋、醫療收據、保單、診斷證明、檢驗報告、公文、不確定 |
   | 生活契約 | 水電瓦斯費、電信費、管理費、租約、公文、不確定 |

5. 按 **開始辨識**。按鈕會變成「辨識中…」,畫面會顯示已經等了幾秒;請不要關閉畫面,讀完會自動打開結果頁。

**選了之後會怎樣**

- 稅單、管理費、水電瓦斯費、電信費會當成帳單讀;醫療收據會當成收據讀。
- **身分證明這一類全部,以及存摺、房地權狀、保單、診斷證明、檢驗報告、租約,現在還不能自動判讀。**
  照樣可以上傳,但不會自動存檔:讀得出來的一律放進「待複核」交給家人看,畫面上會寫您選的名稱(例如「保單」)。
- **醫療與保險、身分證明這兩類,一律只在家裡這台電腦上辨識**;還不能自動判讀的文件也一樣。
- 選的大類決定文件放在「文件櫃」的哪一類。沒選大類時,系統依讀到的種類放(發票、收據放「財產資產」,
  帳單放「生活契約」,藥袋放「醫療與保險」);公文要看內容才分得出來,沒選就放在「未分類」,家人之後可以指定(第 7.3 節)。

**拍清楚的小訣竅**:在光線充足的地方,把文件放平,整張拍進畫面。

**可以上傳的檔案**:照片(JPG、PNG、WEBP、BMP、TIFF)或 PDF,15MB 以內;PDF 只會讀第一頁。

看到下面這些話時:

| 畫面上的話 | 怎麼辦 |
|---|---|
| 請先拍照,或選一個檔案。 | 還沒選照片,先按「拍照」或「選照片」 |
| 這個檔案是空的,請重新拍一張。 | 重新拍一張 |
| 只能上傳照片(JPG、PNG、WEBP、BMP、TIFF)或 PDF。 | 換一個檔案 |
| 檔案內容和副檔名對不上,請直接用相機拍一張,或選原始的照片檔。 | 改按「拍照」直接拍 |
| 檔案超過 15MB。請改拍一張,或選較小的檔案。 | 重拍,或選小一點的檔案 |

## 3. 看結果

### 3.1 最上面:這是什麼、處理得怎樣

- 最上面一行是位置,例如「首頁 / 生活契約 / 電費帳單」;按中間的大類,會打開文件櫃的那一類。
- 標題是文件的種類,例如「電費帳單」「公文」「藥袋」「發票」,或是上傳時在下一列選的名稱(例如「稅單」「保單」)。
- 旁邊寫上傳時間和狀態:
  - **已存檔**:AI 讀到的內容通過核對,該有的欄位也都有。
  - **等待複核**:AI 沒把握、核對不符、少了重要的欄位,或是還不能自動判讀的文件。下面會用一句話說明原因,
    例如「讀到的金額和發票上的 QR Code 不一樣,請對照原件確認。」旁邊有 **更正讀值** 按鈕(第 7 節)。
  - **讀不出來**:會出現「這張讀不出來」和「重新拍一張」按鈕,照上面的小訣竅再拍一次。
- 按「看原件」會跳到您上傳的照片。

### 3.2 要做的事

最上面的方框直接回答「要做什麼、什麼時候前、多少錢」:

| 文件 | 方框裡會看到 |
|---|---|
| 帳單 | 事項(例如「繳電費」)、繳費期限(例如「10月20日前」)、應繳金額;下面寫「期限由 AI 讀取,請對照帳單。」 |
| 公文 | 辦理期限、發文機關、應辦事項(或主旨);下面寫期限是依公文上哪一句算出來的,例如「依公文上的「收到本函後15日內」推算,期限以公文原文為準。」 |
| 藥袋 | 「服藥時間表」:早、中、晚、睡前各有哪些藥;「需要時」吃的藥另外列;藥袋上沒印時段的藥列在「未標時段」,時段請依藥袋或詢問藥師。下面寫「照藥袋上印的字整理,請對照藥袋。」 |
| 發票、收據 | 「文件摘要」:商家、日期、金額 |

- 核對發現不對時,方框最上面會有紅色警示,例如「有 1 項不符,請對照原件」。
- 方框下面一行是提醒的狀態:
  - 「已列入提醒,到期前會列在首頁「要記得的事」。」——不用等任何人確認,已經生效。
  - 「等待家人確認」「家人已確認」「家人已退回」——這件事要家人在「家人確認」點頭才算數(見第 6 節)。
- 公文的期限是程式依原文算的:從發文日期算起,讀不到發文日期就從上傳那天算。實際收到信的日子可能比較晚,
  **期限一律以公文原文為準**。展開「提醒與待辦」可以看到是從哪一天算起。

### 3.3 取消提醒、恢復提醒

- 自動列入的期限提醒,狀態那一行旁邊有 **取消提醒** 按鈕。按一下就取消,不會再問一次;
  畫面上方出現「已取消提醒」,首頁「要記得的事」也不再列出。
- 按錯了沒關係:同一個位置會變成 **恢復提醒**,按一下就恢復。
- 要家人確認的事項沒有這個按鈕,請到「家人確認」確認或退回。
- 家人更正過這份文件後,舊的提醒會換成新的。從更正前就開著的舊畫面按按鈕時,會看到「這個提醒已經換成新的了」,
  請回結果頁看最新的提醒。

### 3.4 唸給我聽

- 按 **唸給我聽**,系統會把「要做的事」方框、藥袋的提醒聲明和白話解說唸出來。
  數字一個一個唸(例如 1,286 元唸成「一 二 八 六 元」),比較不會聽錯。
- 唸的時候按鈕會變成「停止朗讀」,再按一次就停。
- 覺得唸太快,可以到「設定」把這台裝置的朗讀速度改成「慢」(第 8.2 節)。
- 如果看到「這個瀏覽器不能朗讀。請改用手機或電腦上的 Chrome、Safari 或 Edge。」,換一個瀏覽器就好。

### 3.5 AI 白話解說

- 「AI 白話解說」是 AI 讀完整理的一小段話(80 字以內),旁邊標著「AI 產生」。**重要的日期與金額請對照原件。**
- AI 沒有給解說時,標題會變成「重點整理」,內容是系統用讀到的欄位拼成的句子。
- 家人更正過讀值後,AI 的舊解說不再顯示,改成「重點整理」,下面寫「家人更正過讀值,這段是系統依更正後的欄位整理的。」
- 藥袋的頁面一定有這句話:「本系統只協助閱讀,不提供醫療建議;用藥請依醫師與藥師指示。」

### 3.6 核對結果怎麼看

「核對結果」列出程式做過的每一項檢查。這些檢查由程式完成,不是 AI 自己打分數。

| 畫面上的字 | 意思 |
|---|---|
| 相符 | **只用在電子發票**:程式把 AI 讀到的值,和發票左邊 QR Code 裡的資料一格一格比對,結果一樣。QR Code 是開發票時印上去的資料,和 AI 怎麼看照片無關,所以「相符」是比較有力的證據 |
| 不符 | 和 QR Code 不一樣,AI 很可能讀錯了。這份文件不會自動存檔,會交給人確認 |
| 通過 | 程式只檢查格式與合理性(例如統一編號的檢查碼、日期在不在合理範圍)。「通過」只代表沒有明顯讀錯,**不能證明讀對** |
| 沒通過 | 格式或合理性有問題,請對照原件 |
| 無法核對 | 這一項沒有東西可以比對,例如找不到 QR Code |

- 帳單、公文、藥袋、收據沒有 QR Code 可以比對,只會看到「通過/沒通過」,下面會寫
  「這份文件沒有 QR Code 可以比對,程式只檢查格式與合理性,不能證明讀對,請對照原件。」
- 「驗證信心」依核對結果計算,不是 AI 自評。只有格式與合理性檢查的文件,驗證信心最高只到 85%。
- 「讀到的內容」裡,欄位旁可能標著「與 QR 相符」「已檢查」或「不符」;讀不清的欄位寫「讀不清楚,請看原件」,
  該有卻沒讀到的寫「沒有讀到」。

### 3.7 其他區塊

- **提醒與待辦**(按一下展開):這份文件產生的期限提醒或服藥時間表,以及它們現在的狀態。
- **讀到的內容**:AI 讀到的每一個欄位;藥袋另外列出「藥品(照藥袋上的字抄錄)」。最下面的「辨識來源」寫的是哪一個模型讀的。
  讀錯了就按標題旁的 **更正讀值**(第 7 節)。
- **原件**:您上傳的照片(電腦版在右邊,手機和平板在下面)。按「放大看原件(另開新頁)」可以看清楚細節;
  PDF 沒辦法在頁面上預覽,請按「另開原檔」。

## 4. 首頁「要記得的事」

依這個順序列出,最多 6 件,按任何一列就會打開那份文件:

1. 等待家人確認的事
2. 還沒到期的期限提醒(日子近的在前;左邊有日期方塊,帳單會寫金額)
3. 核對不符或檢查沒通過的文件
4. 家人已確認的服藥時間表

- 期限過了、已取消、被退回的提醒不會列出。
- **提醒只有打開「看有」時才看得到**:系統不會傳訊息、不會響鈴,也不會加進手機的行事曆。
  請每天打開看一下,或請家人幫忙看。
- 下面的「最近看過的文件」列出最近 8 份,狀態一樣是「已存檔」「等待複核」「讀不出來」。

## 5. 文件櫃

「文件櫃」把所有文件依四大類整理:身分證明、財產資產、醫療與保險、生活契約。

- 最上面四張卡片寫著每一類放什麼(例如財產資產:發票、收據、稅單)和有幾份。按一張卡片,就只看那一類。
- 下面依大類列出文件,每一列按下去就是那份文件的結果頁;「讀不出來」和「等待複核」的文件也算在份數裡。
- 沒選大類的公文放在「未分類」,列在最後;家人可以在「更正讀值」指定它屬於哪一類(第 7.3 節)。
- 身分證明類還沒有文件時,會寫「身分證明類(身分證、健保卡、戶口名簿)初賽還不能自動判讀,拍了會交給家人複核。」

## 6. 家人確認(給家人)

「家人確認」只列出需要家人點頭的事,一件一張:

- **藥袋的服藥時間表**:一律要家人確認才算數。
- **轉到待複核的帳單或公文,它們的期限提醒**:已存檔的帳單與公文會自動列入提醒,不會出現在這裡。

每一張寫著這是什麼、來自哪一份文件、什麼時候上傳,並有「看原件與全文」連結;寬螢幕會把原件照片放在旁邊,方便逐項對照。

- 沒問題就按 **確認**,狀態變成「家人已確認」,這件事會列進首頁「要記得的事」。
- 不對就按 **退回**。畫面中間會跳出確認框,例如「確定要退回「服藥時間表」嗎?」「退回後就不會生效。」:
  - 按 **確定退回**,狀態才變成「家人已退回」。**退回之後在系統裡沒辦法復原。**
  - 按 **先不要**(或按鍵盤的 Esc)就什麼都不做。框一打開,預設選在「先不要」上,不小心按到 Enter 也不會退回。
  - 確認框剛跳出來的半秒內,點框上的按鈕不算數——不小心連點兩下「退回」,也不會沒看清楚就退回。
- 看到「這件事可能已經有人處理了,請回「家人確認」看最新狀態。」,代表別人已經按過了。
- 服藥時間表或期限讀錯了,不必退回:到那份文件按「更正讀值」改正(第 7 節),系統會重新整理服藥時間表或重算提醒。
- 目前不會記下是誰按的,能打開網頁的人都能確認或退回;區分長輩與家人的身分是規劃中(決賽前做)。

## 7. 待複核與更正讀值(給家人)

### 7.1 待複核清單

AI 沒把握、核對不符、少了重要的欄位、不是支援的文件類型,或是還不能自動判讀的文件(身分證明、保單…),會放進「待複核」。
清單上每一份都寫出白話的原因、上傳時間與驗證信心(沒有可核對項目的寫「沒有可核對的項目」)。按一份就打開它的「更正讀值」。

### 7.2 更正讀值

任何類型的文件都能更正:待複核的文件從清單進來;已存檔的文件,在結果頁「讀到的內容」旁按 **更正讀值**。
讀不出來的文件沒有讀值可改,請重新拍一張。

左邊是表單,右邊是原件(手機和平板的原件在最下面,按「看原件」跳過去)。**對照原件,只改讀錯的地方。**

| 文件 | 表單上可以改的 |
|---|---|
| 帳單 | 帳單種類(電費、水費、瓦斯、電信、其他)、繳費期限、應繳金額(元)、開單單位、開單日期 |
| 公文 | 發文機關、發文日期、主旨、期限原文(照公文上的寫法,例如「收到本函後15日內」;日期由系統計算)、發文字號、應辦事項(一行一項) |
| 藥袋 | 醫療院所、調劑日期;每一種藥的藥名、用法(照藥袋上的字)、什麼時候吃(早、中、晚、睡前、需要時,可以選好幾個)、天數。少一種藥就按「再加一種藥」 |
| 發票、收據 | 日期、商家、金額、幣別(台幣填 NTD)、發票號碼 |

- 標著「必填」的欄位一定要填。日期可以寫 2026-10-20,也可以寫民國年(例如 115/10/20),系統會換算。
- 藥袋只照抄藥袋上印的字;系統不判斷劑量或用法,存檔後服藥時間表仍要家人確認。
- 文件的種類(例如帳單、收據)不能在這裡改。
- 改好了按 **存檔並重新核對**;不想改了按 **不改了**,回到結果頁。

### 7.3 這份文件屬於哪一類

表單下面有「這份文件屬於哪一類」:身分證明、財產資產、醫療與保險、生活契約、未分類。它只決定文件放在文件櫃的哪一類。

- 只改了類別、讀值沒動時,畫面上方出現「已更新類別」;不會重新核對,已取消的提醒、已確認的服藥時間表都維持原狀。

### 7.4 存檔之後

- 畫面回到結果頁,上方出現「已更正」。
- 程式會**重新核對一次**,並**重新計算提醒**(帳單、公文)或**重新整理服藥時間表**(藥袋);舊的提醒換成新的。
  公文讀不到發文日期時,期限仍從原本上傳的那天起算,不是更正的那天。
- 核對都沒問題、該有的欄位也都有,文件就變成「已存檔」;還有問題(例如金額和 QR Code 還是不一樣),
  文件會留在(或改放到)「待複核」並說明原因。
- 改的是同一份文件,不會多出一份。

### 7.5 填錯時

存不進去時,畫面會寫「有 N 個地方要修改,請看下面紅字的說明。」,已經填的內容都還在,照紅字改好再按一次:

| 紅字 | 怎麼改 |
|---|---|
| 這一欄必填,請對照原件填上。 | 這一欄不能空白 |
| 請填正確的日期,例如 2026-10-20。 | 日期寫法不對 |
| 只填數字,例如 1286。/ 金額要大於 0。 | 金額只填數字,不要加「元」 |
| 只填天數的數字,例如 7。 | 天數只填數字 |
| 請填 3 個英文字母,台幣填 NTD。 | 幣別寫法不對 |
| 太長了,最多 500 個字。 | 縮短一點 |

### 7.6 退回(品質不足)

照片太糊、沒辦法判斷時,在待複核文件的更正頁最下面按 **退回(品質不足)**。會跳出確認框
「確定要退回這份文件嗎?」「這份文件會改成「讀不出來」,請長輩重新拍一張。」:按 **確定退回** 才會退回,按 **先不要** 就不退。
退回後,這份文件變成「讀不出來」,它的提醒也不再生效;請重新拍一張。

## 8. 設定

「設定」分成四塊。

### 8.1 系統狀態(只看,不能改)

寫出現在的辨識模式與本機的 AI 模型連不連得上、使用的模型、哪些文件只在這台電腦處理、自動存檔門檻,以及版本。
看到「模型連不上」時,請家人或管理者檢查家裡那台電腦。

### 8.2 這台裝置

- **字級**:標準、大、特大。**朗讀速度**:慢、標準。
- 改了馬上生效,只存在這台手機或電腦,不影響家裡其他人的手機。
- 看到「這個瀏覽器不讓網頁記住設定(例如無痕模式),換頁後會回到預設。」時,換成一般的瀏覽器視窗再設一次。

### 8.3 系統設定(會影響全家)

- **辨識模式**:「只用這台電腦」或「可以用雲端備援」。家裡那台電腦還沒設定雲端的帳號與金鑰時,雲端備援不能選。
  從「只用這台電腦」改成雲端時,按「儲存設定」會先跳出確認框「確定要開啟雲端備援嗎?」,按 **確定開啟** 才會改。
- 不論選哪一種,**藥袋、醫療與保險、身分證明一律只在這台電腦處理,這一項不能關**。
- **自動存檔門檻**:驗證信心達到這個比例才自動存檔,其餘交給家人複核。可以選 80%、85%、90%、95%,只能調得更嚴,不能低於 80%。
- 按 **儲存設定**;畫面上方出現「已儲存設定」(沒改任何東西時是「設定沒有變動」)。
- 下面的「最近的設定變更」列出什麼時候、改成什麼;從外面經登入使用時,也會寫是哪個帳號改的。

### 8.4 資料管理

- **匯出全部紀錄**:下載一個檔案,裡面有所有文件的讀值、提醒與服藥時間表、更正紀錄與設定變更;不含照片。
  **檔案裡有文件內容,請存在安全的地方。**
- **刪除全部資料**:會先跳出確認框「確定要刪除全部資料嗎?」「所有文件的照片、讀值、提醒與更正紀錄都會刪除,無法復原;
  設定與設定變更紀錄會保留。」按 **確定刪除** 才會刪。刪完回到首頁,上方出現「已刪除全部資料」。
  **刪除後無法復原**,需要的話請先匯出。

## 9. 隱私

- 預設**所有文件都在家裡這台電腦上辨識**,不會送到雲端。
- 家人可以在「設定」改成「可以用雲端備援」:有選種類的帳單、公文、發票、收據(以及稅單、管理費、水電瓦斯費、電信費)
  會交給雲端模型讀取;**藥袋、醫療與保險與身分證明兩類、還不能自動判讀的文件,以及沒選種類的文件,仍然只在這台電腦上辨識**。
  每一頁的安心說明會寫出目前是哪一種模式。
- 雲端模式下請選對種類:如果把藥袋選成發票之類的其他種類,照片在辨識前就已經送到雲端,事後收不回來。
  拍藥袋時請選「醫療與保險」,不確定時請選「不確定」。
- 送給 AI 之前,系統會先去掉照片裡的拍攝地點(GPS)等資訊。
- 照片和結果存在這台電腦裡;瀏覽器不會把原件留在快取裡。
- 要拿走或清掉所有資料,用「設定」的「匯出全部紀錄」與「刪除全部資料」(第 8.4 節)。
- 從家裡以外的地方用手機打開時,登入由 Cloudflare Access 負責,設定方式見[部署指南](部署指南.md)。

## 10. 系統不做的事

- **不付款、不送出回覆、不簽署任何東西**。要不要繳、要不要回覆公文,由您和家人決定。
- **不給醫療建議**:不解釋藥效、用途或副作用,也不把「一天三次」換算成早中晚;用藥請依醫師與藥師指示。
- **不保證讀對**:AI 可能讀錯。只有電子發票能用 QR Code 比對;其他文件的日期與金額,請一定對照原件。
- **不推播通知**,也不加進手機行事曆;提醒只列在首頁「要記得的事」。
- 只自動判讀發票、收據、帳單、公文、藥袋(稅單、管理費這類當帳單讀);身分證、保單等其他文件會放進「待複核」。PDF 只讀第一頁。
- **還不會「越用越準」**:家人改過的內容會記下來,但目前不會讓下一次讀得更準(規劃中,決賽)。
- **還不分長輩與家人的身分**,也不記下確認、更正、退回是誰按的(規劃中,決賽前)。

## 11. 給開發者

- 安裝、測試與啟動:見 [README](../README.md) 的「快速開始」(macOS/Linux 與 Windows 各一組指令;Windows 跑測試要先設 `PYTHONUTF8=1`)。
- 沒有模型也能看完整畫面:README 的「展示模式」——先用 `tools/make_demo_docs.py`、`tools/make_sample.py --einvoice`
  產生合成文件,再執行 `tools/demo_server.py --reset --seed`,瀏覽器開 `http://localhost:8000`。
  展示模式的讀值是預錄的模擬資料(安心說明會寫「展示模式」);核對、決策與行動都是真實程式的結果。
- 設定:README 的「設定」與 `config.yaml`;設定頁能改的辨識模式與門檻存在 SQLite,蓋過 `config.yaml`。
- 系統怎麼運作:[系統架構](系統架構.md);對外部署:[部署指南](部署指南.md)。

### 建立標準答案

`tools/evaluate.py` 找不到標準答案時會請您看這一節。

- 評測只用合成樣本。在專案根目錄執行 `python tools/make_sample.py --einvoice`,會在 `data/samples/einvoice/`
  產生合成電子發票與它自己的標準答案 `labels.csv`;`tools/evaluate.py` 預設就讀這個資料夾(`--samples` 可改)。
  另有合成發票與收據:`python tools/make_sample.py` 產生到 `data/samples/synthetic/`(`--out` 可改;已有標準答案時要加 `--force` 才會覆寫)。
- 欄位:`檔名,doc_type,date,vendor,amount,invoice_number`(多的欄位不讀);日期一律西元 `YYYY-MM-DD`;
  `doc_type` 必填,其他欄位留空就不列入比對。
- 不要把真實文件或真實的標準答案放進 `data/samples/`;`--samples` 指到 `data/samples/` 根目錄時工具會警告。
- 評測在 GPU 電腦執行:`tools/evaluate.py --model gemma4:12b`(沒有模型時可先用 `--mock` 確認流程跑得通,Mock 的結果不是模型表現)。
  每次執行會整份重寫自動產生的報告 `docs/模型實測結果.md`。2026-10-03 的實測:`gemma4:12b` 讀 11 張合成電子發票,
  類型、日期、金額全對 10 張,平均 3.25 秒/張(RTX 5070 Ti 16GB);帳單、公文、藥袋還沒有標準答案,沒有正確率數字。
